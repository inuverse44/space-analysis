# 分析計画書：地球の電波は、どの星まで届いたか ―『三体』になぞらえて

データ解析の見本その 2。SF 小説『三体』では、地球から出た電波が別の星系に届くところから物語が動き出す。現実の地球もラジオやテレビの電波を宇宙に出し続けている。その電波がどこまで届いたかを、公開データで確かめる。

小説の本文や画像は使わない。作品名に触れて、テーマをなぞらえるだけにする。

## 1. 目的

| ID | 目的 |
| --- | --- |
| G-01 | 身近で引きのあるテーマで、データの集計・可視化をどう進めるかを見せる |
| G-02 | データの限界（カタログの抜けや距離の誤差）も含めて、誠実に伝える |
| G-03 | 誰でも同じ結果を再現できる形にする |

## 2. 問い

| ID | 問い |
| --- | --- |
| Q-01 | 地球の電波は、いまどこまで届いていて、その中に星はいくつあるか |
| Q-02 | 電波が届いた範囲に、惑星が見つかっている星はいくつあるか |
| Q-03 | 『三体』の舞台のモデルになった、ケンタウルス座アルファ星系はどんな星たちか |

## 3. データ

| ID | データ | 内容 | ライセンス・出典 |
| --- | --- | --- | --- |
| D-01 | HYG Database v4.4 | Hipparcos・Yale 輝星表・Gliese 近傍星表をまとめた恒星カタログ（約 12 万個）。距離、明るさ、スペクトル型など | CC BY-SA 4.0。https://codeberg.org/astronexus/hyg |
| D-02 | NASA Exoplanet Archive「Planetary Systems Composite Parameters」 | 見つかっている系外惑星と、その恒星の距離など | 謝辞と Christiansen et al. (2025) の引用を求められている。https://exoplanetarchive.ipac.caltech.edu/ |

- Gaia DR3 はより完全だが、データのライセンスが非営利に限られる（CC BY-NC 3.0 IGO）。このリポジトリは MIT ライセンスで公開しており、利用目的に制限のつくデータは混ぜないため使わない。
- HYG は、明るい星と、よく知られた近くの星は網羅しているが、暗い赤色矮星や褐色矮星は抜けている。数は「知られている星の数」として扱い、レポートにこの限界を書く（G-02）。
- D-02 は日々更新されるので、取得した時点のものを保存する。取得日、問い合わせの内容、SHA-256 を記録する。

## 4. 手法

| ID | 手法 | 定義 |
| --- | --- | --- |
| M-01 | 電波の到達半径 | 基準日（データを取得した日）までに、出来事の日から光が進んだ距離。1 光年はユリウス年（365.25 日）で光が進む距離 |
| M-02 | 範囲内の星の数 | 太陽からの距離が到達半径以下の恒星の数（太陽自身は数えない）。距離が不明のものは除く |
| M-03 | 範囲内の惑星系 | 恒星までの距離（`sy_dist`）が到達半径以下の惑星系の数と、惑星の数 |
| M-04 | 星の比較 | 距離、明るさ（太陽 = 1）、スペクトル型を、太陽と比べる |

到達半径の目安にする出来事（基準日は 2026 年 10 月）：

| ID | 出来事 | 日付 |
| --- | --- | --- |
| E-01 | 米国 KDKA 局がラジオの定時放送を始める | 1920-11-02 |
| E-02 | ベルリン・オリンピックのテレビ中継 | 1936-08-01 |
| E-03 | アポロ 11 号の月面からのテレビ中継 | 1969-07-21 |
| E-04 | アレシボ・メッセージの送信 | 1974-11-16 |

- 「届いた範囲」は光の速さで計算した理論上の範囲。届いた電波が受信できる強さかどうかは、この分析では扱わない（レポートに明記する）。

## 6. 検証

| ID | 検証 | 根拠 |
| --- | --- | --- |
| V-01 | 保存したデータの SHA-256 が記録と一致する | 取得したデータの同一性 |
| V-02 | HYG の距離の単位がパーセクで、プロキシマ・ケンタウリまでが 4.2〜4.3 光年になる | 広く知られた値（約 4.24 光年） |
| V-03 | 到達半径の計算：1 年前に出た光の半径が 1 光年になる、など手計算の例と一致する | M-01 の定義 |
| V-04 | 範囲内の星の数が、半径が大きくなるほど減らない（単調に増える） | M-02 の定義 |
| V-05 | プロキシマ b が D-02 にあり、恒星までの距離が 1.3 パーセク前後 | よく知られた値 |
| V-06 | 加工済みデータとレポートが、コードから毎回同じものとして作り直せる | G-03 |
